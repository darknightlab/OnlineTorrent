# 前端设计 / UX 评审（web/）

评审范围：首页、/latest、/search、/anime/:key、/watch、/login、/register、/me、/admin/*（全部 9 个页面）。
视口：360、390、820、1024、1440；浅色和深色两套主题都看过。数据：真实后端 :8080（admin 已登录）；VIP / 屏蔽 / 需登录拦截页和公告用 mock 构建验证。
截图：`/tmp/r/a/`（修复前，真实后端）、`/tmp/r/m/`（修复前，mock 拦截页）、`/tmp/r/b/`（修复中间态，360/1024）、`/tmp/r/c/`（修复后）。
文件命名：`<path>-<width>-<theme>.png`；`.sN.png` 是按视口高度切的分段图。

整体评价：设计语言统一，组件都基于同一套 token（主色 #4caf50、强调色 #2196f3、圆角 0.625rem、同一种卡片阴影），深色模式下绿色文字用的是 #81c784，对比度足够。任何页面、任何视口都没有出现横向滚动（脚本检查了 `scrollWidth > innerWidth`）。时间表按星期分 Tab，竖版封面，左上角是播出时间，右上角是状态，左下角是集数，加上播放按钮，接近巴哈姆特动画疯的信息密度：每行手机 3 张、平板 5 张、1024 宽 6 张、≥1280 宽 8 张。

## 未处理 / 建议

- **主色按钮上的白字对比度只有约 2.8:1**（#4caf50 配 #fff），低于 WCAG AA 的 4.5:1。主色是业主定死的，所以没改。可以考虑的做法：按钮文字一律加粗（现在已经是 medium），或者把小号白字角标的底色换成 #388e3c。
- 番剧页在桌面端，“播放最新一集”和外链按钮贴着封面底部对齐（`mt-auto`），封面高时，中间会空出一块。这样做保持了和封面底边对齐，算是可以接受的设计。
- 番剧简介在手机端折叠为 4 行时，如果原文里有空行，可见的正文会更少。
- 站点设置页底部的保存栏一直显示（“已修改 0 项”）。可以改成只在有修改时才出现。
- 播放页的分集角标里，番名来自种子解析结果（例如“蓝箱”和“青之箱”），会和番剧的中文名不一致。这需要后端统一番名。
- 后端 :8080 是在编译时用 embed 打包 dist 的，所以本次修改要等 Go 重新编译后才会在 :8080 上生效。本次验证用的是 `vite preview`（代理到 :8080）和 mock 构建。
